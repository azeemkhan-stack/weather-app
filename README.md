# SkyCast - Weather Dashboard

A simple weather web app made with HTML, CSS and JavaScript.

## What it does

- Search any city and see its current weather
- Shows temperature, humidity, wind, and weather condition
- Hourly forecast and 7-day outlook
- Light and dark theme
- Recent searches saved in the browser

## Data

Weather data comes from the free Open-Meteo API. No API key is needed.

## Run locally

Open `index.html` through a local web server (for example `python3 -m http.server`)
and visit http://localhost:8000 in the browser.
